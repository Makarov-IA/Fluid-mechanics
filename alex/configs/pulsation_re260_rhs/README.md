# pulsation_re260_rhs

Поправка −dt·P(z−z*) в обеих правых частях; коэффициенты заморожены в начале шага, gain=1.

Общие параметры: область 1×0.5, 201×101, Re=260, dt=1e-5, 10⁶ шагов до псевдовремени 10, нулевое начальное состояние и неподвижные стенки. Аракава, прежняя факторизация.

Проекция по полной паре внутренних ψ и ω, обычная евклидова норма без весов; общий коэффициент для обеих компонент. Файл базиса один для двух способов. Кандидат и Ньютон найдены по базовой задаче; моды построены по физическому оператору, а не по карте шага псевдовремени.

Полное вычитание и RHS с gain=1 имеют разную силу воздействия на один шаг: это часть сравнения, не доказательство преимущества порядка операций при равных усилениях.
