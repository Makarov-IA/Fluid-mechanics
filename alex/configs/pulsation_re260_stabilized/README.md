# pulsation_re260_stabilized

Та же задача, что pulsation_re260, с обратной связью −P(ω−ω*) в правой части уравнения завихренности; gain=1. Файл стационара и базиса создаётся анализом базового расчёта. Это управление в псевдовремени, а не физическое граничное управление.

Результаты: `alex/results/pulsation_re260_stabilized/`. Схема всегда факторизованная, якобиан Аракавы. Параметры запуска и потоки находятся в YAML.
