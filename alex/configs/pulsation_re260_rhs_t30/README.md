# pulsation_re260_rhs_t30

Продолжение `pulsation_re260_rhs` из состояния τ=10 ещё на 20 единиц псевдовремени: 2000000 новых шагов, dt=1e-5. Общая длительность исходной траектории — τ=30.

Поле ψ и поле ω явно загружаются через resume из последнего снимка своего варианта. Сетка 201×101, Re=260, источник, стенки, Аракава, факторизация и управление сохранены. Базис управления тот же.

Время новых бинарных снимков локальное, от dt до 20; для сопоставления с исходной траекторией прибавить 10. Проверено побитовое совпадение загруженных полей с исходным снимком.

Запуск: выбрать этот эксперимент в `solver_python_run/settings.sh` и использовать обычный `run.sh`, либо передать этот YAML существующему `solver_python/run.py`.

Расчёт завершён: 2000000 новых шагов, локальная τ=20, общая τ=30. Итоговые исходные невязки: Rψ=1.73550063e-11, Rω=2.48877574e-09; converged=False. Сравнение и общий график находятся в `results/pulsation_re260_base_t30/figures/`.
