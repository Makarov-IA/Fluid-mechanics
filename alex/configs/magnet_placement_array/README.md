# Массив конечных магнитов: сравнение количества

Запуск из `alex/`: `bash solver_python_run/design_magnets.sh`.
Всё задаётся в `magnet_placement_array.yaml`. Это вход для `magnet_design.py`,
не для основного `run.py`. Результаты — `results/magnet_placement_array/`.
Прежний опыт с двумя магнитами сохранён отдельно.

## Геометрия и физические допущения

Магниты 10 × 10 × 5 мм, вертикальная однородная намагниченность, модельная
номинальная M = 800000 А/м. Размеры, ток (0, 0.1) А/м², плотность и масштаб
скорости сохранены от первого прототипа. Между верхней гранью и внешним дном
5 мм, толщина дна 2 мм, плоскость расчёта на 2 мм над внутренним дном.
Итого от верхней грани магнита до плоскости расчёта 9 мм.

Кювета 24 × 12 см. **Явное изменение геометрии:** допускается монтажная рамка,
выходящая на 12 мм за каждый край кюветы (`frame_extension_m`). Некоторые
магниты находятся под краями или снаружи проекции дна; на графиках зелёная
рамка обозначает именно кювету. Это модельная возможность монтажа, не
подтверждённая конструкция установки. `edge_clearance_m` отсчитывается от
внешней рамки. Ограничения размеров и расстояний между магнитами сохраняются.

## Подбор и проверка

1. Строится 231 непересекающееся допустимое место на сетке 21 × 11.
   `candidate_pitch_m` задаёт минимальный шаг, фактический шаг равномерно
   распределяется по доступной ширине. Не меняется сетка течения 201 × 101.
2. Для каждого места аналитически вычисляется поле конечного магнита и
   источник завихренности на **всех внутренних узлах** сетки течения.
3. Магниты добавляются последовательно с минимизацией худшей ошибки по
   комбинациям двух omega-компонент `state_basis`. Все амплитуды каждый раз
   переподбираются совместно. При первом выборе вырожденный критерий
   разрешается суммарным перекрытием обеих мод. Скалярные произведения
   ускоряют поиск без огрубления сетки. Контрольные точки независимо
   проверяются прямым SVD-решением задачи на полной сетке.
4. Сравниваются 2, 6, 12, 24, 48, 96, 144, 192 магнита. Это вложенные наборы,
   а не случайная независимая оптимизация каждой размерности. Дополнительно
   оцениваются все 231 место — предел аппроксимации **данного словаря**.
   Глобальный оптимум непрерывных координат не заявляется.

Для `G C ≈ E` управление имеет вид `u = -gain*C*a`. Амплитуда u_i умножает
номинальный отклик i-го магнита. Она предполагается независимо изменяемой
по величине и знаку; постоянные магниты с одним общим током этого не дают.

## Ограничение амплитуд

Радиус коэффициентов R = max ||a|| = 601.185 берётся из сохранённого
базового расчёта 0–30. YAML ссылается на таблицу; отчёт сохраняет её SHA256.
При gain=1 и ||a|| ≤ R требуется |u_i| ≤ 1 для каждого магнита. Проверяется
строгое равенство `sup |u_i| = gain*R*||C_i||₂`. Ограничение гарантировано
только в этом шаре коэффициентов, а не для произвольных будущих возмущений.

Если обычный МНК превышает лимит, подбирается общая регуляризация Тихонова
до выполнения всех ограничений строк C. Это **допустимое, но не доказанно
оптимальное решение ограниченной задачи**. Геометрия выбирается по
неограниченному МНК; ограниченный результат оценивается отдельно. В таблице
есть обе ошибки, максимальные амплитуды и параметр регуляризации. Лимит
задан для идеализированного актуатора; токи катушек, мощность, гистерезис и
взаимное размагничивание не моделируются.

## Полученные результаты

Худшая относительная ошибка формы с ограничением амплитуд:

| Магнитов | Ошибка |
|---:|---:|
| 2 | 99.10% |
| 6 | 97.33% |
| 12 | 94.99% |
| 24 | 91.72% |
| 48 | 80.62% |
| 96 | 61.35% |
| 144 | 51.64% |
| 192 | 45.24% |
| Все 231 место | 44.69% |

Нельзя утверждать, что 192 магнита воспроизводят нужную поправку точно:
остаток существенен. Нельзя делать вывод о невозможности стабилизации
меньшим числом актуаторов: динамическая управляемость здесь не исследуется.
Поправка к psi и физическая реализация исходного гармонического источника
не проектируются. Солвер и схема Аракавы не меняются.

## Файлы результатов

- `figures/count_comparison.png`, `count_comparison.csv`: ошибка и амплитуда
  в зависимости от количества.
- `figures/magnet_layout.png`: выбранные 192 места в масштабе.
- `figures/magnet_amplitudes.png`: знаки и веса C для каждой моды.
- `figures/mode_fit.png`: цель, ограниченное приближение и остаток.
- `figures/magnet_responses.png`: индивидуальные отклики первых 4 магнитов.
- `placement.yaml`: координаты и размеры; не конфиг солвера.
- `report.json`: результаты, ограничения, происхождение и статус поиска.
- `design.npz`: выбранные отклики G, целевые профили E, ограниченные C и G C.
- `candidate_sites.npz`: все места и порядок выбора; основной результат
  в `design.npz` отсортирован по координатам, порядок добавления сохранён отдельно.
- `design.input.yaml`, `design.resolved.yaml`: параметры запуска.

Тесты проверяют поле независимой квадратурой, производные, нормировку,
сходимость критерия поиска с полным SVD, ограничения амплитуд и геометрию.
