# pulsation_re260

Базовый расчёт с гармоническим источником, Re=260, 201×101, область 1×0.5. Миллион шагов по 1e-5 до псевдовремени 10. Неподвижные стенки, прилипание, без придонного трения. Служит для поиска стационара и неустойчивых мод.

Результаты: `alex/results/pulsation_re260/`. Схема всегда факторизованная, якобиан Аракавы. Параметры запуска и потоки находятся в YAML.
