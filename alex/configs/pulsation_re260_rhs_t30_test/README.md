# pulsation_re260_rhs_t30_test

Проверка **прибавления** неустойчивой проекции вместо вычитания. Все параметры
и начальные условия совпадают с `pulsation_re260_rhs`; единственное отличие
в содержимом YAML — `stabilization.gain: -1.0` вместо `1.0`.

Начальные ψ = 0, ω = 0, блока resume нет. Сетка 201×101, Re=260, dt=1e-5,
1000000 шагов до **псевдовремени τ=10**. Название папки с t30 оставлено по
выбору пользователя; оно не означает длительность расчёта. Стенки неподвижны,
исходный источник custom/harmonics, магнитов нет. Аракава и факторизация прежние.

Управление задаётся парной проекцией P(z−z*), z=(ψ,ω). В каждой правой части
применяется −dt·gain·P, поэтому при gain=−1 поправка **прибавляется**.
Коэффициенты общие для ψ и ω, вычисляются из старой пары в начале шага.
Это не операция прибавления после шага. Невязки исходных уравнений считаются
без управления. На целевом стационаре поправка исчезает.

Запуск из alex/:

```bash
../.venv/bin/python solver_python/run.py --config configs/pulsation_re260_rhs_t30_test/pulsation_re260_rhs_t30_test.yaml
```

Результаты: `results/pulsation_re260_rhs_t30_test/`.
YAML переименован в соответствии с тестовой папкой, чтобы не перезаписать
старые результаты `pulsation_re260_rhs_t30`. Ранее начатое продолжение из τ=10
остановлено по уточнению пользователя; его снимки заменены текущим запуском.
