# Архив

Здесь сохранены прежние реализации `cpu/`, `gpu/`, запуск `RUN`, старые `scripts/`, `pipeline/`, материалы `paper/`, `presentation/`, `docs/`, `codex_handoff.zip` и прежние результаты.

`results_by_category/` сохраняет старую организацию результатов других задач. Актуальные Python-расчёты перенесены в `../results/<имя>/`.

`maintenance/before_cleanup/` — копия Python и документации до реорганизации. `maintenance/migration.json` перечисляет перемещения; файлы при переносе проверены по inode и размеру. `maintenance/` также содержит контрольные поля, замеры и временные результаты проверки. Старые исполняемые файлы и относительные пути сохранены как исторические материалы; активные команды находятся в `../solver_python_run/`.
